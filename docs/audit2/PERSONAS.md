## 统一 finding 模板

```
[P0|P1|P2] 标题
证据: 命令+输出 或 file:line（无证据不收录）
影响: 谁会疼、疼在哪
修法: 具体到文件与函数
验收: Given/When/Then，必须是可执行断言
工作量: S(≤2h) M(≤1d) L(>1d)
```

## 聚合规则（沿用第一轮）

1. **去重**：同根因合并，保留最严重证据链；跨视角重复 = 置信度 +1。
2. **ICE 打分**：`impact × frequency × confidence ÷ effort(S=1/M=2/L=4)`。
3. **三分类**：立刻做（P0 全部 + ICE 前 30%）/ 本轮做（P1）/ 记台账（P2 与 >1 周工程）。
4. **证伪优先**：N09 的「宣称与现实不符」全部按 P0 处理——假文档比没文档更危险。
