# 11 种风格配方（美术 + 技术 + 音色）

每个风格段 = 3 s / 6 拍。通用结构：

| 拍 | 时间 | 画面任务 |
|---|---|---|
| 0 | 0.00 | 硬切 + 卡点冲击（白闪/缩放/抖动），主视觉第一帧已成立 |
| 1 | 0.50 | 主视觉入场（滑入/生长/翻页） |
| 2 | 1.00 | 标题/主文案到位 |
| 3 | 1.50 | 叙事推进（第二元素/数据/镜头运动） |
| 4 | 2.00 | 细节/装饰/标签弹出 |
| 5 | 2.50 | 收束：所有元素到达最终构图，最后一拍留给下一段硬切 |

**通用规则**
- 左上胶囊：`0X 风格名 · 分类`，编号色随主题（默认珊瑚）+ 白/黑字，圆角 999；
- 右下 3 秒倒计时或帧计数（样片惯例）；
- 右上品牌水印/HUD，透明度 ≤ 0.5；
- 段首第一帧必须“满”：主视觉 + 标题 + 底色已经成立，不要从黑屏开始；
- 每段只用 1 个主视觉 + 1 句主文案 + 2–3 个辅助元素；3 秒内信息过载必花。

技术选型矩阵：

| 风格 | 首选 | 关键能力 |
|---|---|---|
| 01 扁平科普 | Canvas 2D | 渐变、路径、旋转、裁剪、星空粒子 |
| 02 数学动画 | Canvas 2D + KaTeX DOM | DFT 本轮、发光线条、公式排版 |
| 03 发布会 | Canvas/HTML 大字 + Three.js | LatheGeometry、PhysicalMaterial、环境反射 |
| 04 手绘白板 | SVG + Canvas | stroke-dashoffset、feTurbulence、手绘字体 |
| 05 赛博故障 | Canvas 2D | 渐变/条纹/透视网格、切片、通道偏移 |
| 06 水墨国风 | Canvas 2D | fbm 山峦、噪声纹理、墨色渐变、竖排文字 |
| 07 数据可视化 | Canvas 2D（可选 CSS 3D） | 条形动画、发光、透视变换、玻璃卡 |
| 08 8-bit | Canvas 2D 低分辨率 | image-rendering: pixelated、精灵图、视差 |
| 09 代码录屏 | Canvas 2D（DOM 也可） | 编辑器 UI、逐字文本、实时预览 |
| 10 3D 粘土 | Three.js | PhysicalMaterial、软阴影、环境反射、相机环绕 |
| 11 竖屏 | Canvas 2D | 手机壳、描边字、弹出卡片、粒子心 |

## 01 扁平插画科普「为什么会有四季？」

**观感**：深蓝夜空里的扁平太阳系，明亮、圆润、无描边，靠色块和光晕讲科学。

**调色板**
```
bg:    #0a1a3f → #04091a（径向，中心稍亮）
sun:   #ffd24a / #ff9a2e / #ff6a3d（分层圆）
earth: #2f6fd0（海）/ #3fae63（陆）/ #eaf4ff（极冠）
orbit: rgba(255,255,255,.25) 虚线
accent:#d97757
```

**构图**
1. 星空底 + 稀疏星点（种子随机，亮度分级）；
2. 太阳：外圈光晕 → 橙黄大圆 → 亮黄内圆；12 个三角光芒绕圆心旋转（每根错相位）；
3. 虚线椭圆轨道（旋转 -12°），地球沿轨道参数化运动；
4. 地球：蓝色圆 + 绿色大陆色块（用多边形近似）+ 上下极冠；按太阳方向做背光半球压暗（半透明黑覆盖 + 渐变）；
5. 太阳→地球半透明锥形光束（`globalCompositeOperation='lighter'`，低透明度）；
6. 标题左上：「为什么会有四季？」，ZCOOL KuaiLe；「四季」下垫珊瑚色高光条（不是下划线，是一块 8px 高的色条，稍微超宽）；
7. 标签胶囊按拍弹出：「夏至·北半球夏天」「秋分」「冬至·北半球冬天」。

**动效（6 拍）**
- 拍 0：卡点冲击 + 太阳光晕闪一下；
- 拍 1–4：地球沿轨道从左经前方到右侧；标签依次弹出（带 1.06→1 缩放 + 透明度）；
- 拍 5：所有元素轻微漂移，标题高光条向右扫光。

**实现提示**
- 地球轨道：`x = cx + a*cos(θ), y = cy + b*sin(θ)`；`θ = θ0 + k*u`；前后遮挡用绘制顺序（后半段先画地球再画太阳）。
- 背光：在地球上叠加一个以太阳反方向为中心的径向渐变黑。
- 太阳光芒：`ctx.save/translate/rotate`，长三角形，每个旋转速度略不同。

**音色**：马林巴（正弦+泛音，短衰减），每拍和弦根音，第 3 拍加高八度。

## 02 数学动画「傅里叶级数：用圆作画」

**观感**：深色科技感 + 金色数学之美；从左到右「用圆画出心形」的过程。

**调色板**
```
bg:    #070b16
grid:  rgba(88,196,221,.10)（细网格 60px）
gold:  #ffd76a（发光线）
pink:  #ffb3c7（填充）
cyan:  #58c4dd
text:  #f5f0e8
```

**构图**
- 左侧 2/3：本轮作图区；36 个圆链（每个圆的半径/相位来自心形线 DFT 系数），末端轨迹点画金色心形；
- 右侧 1/3：标题「傅里叶级数：用圆作画」+ KaTeX 公式 `f(t)=Σ c_n e^{int}`、`c_n = 1/2π ∫ f(t)e^{-int} dt`；下方实时 `N = 18`、`θ = 3.54`；
- 底部等化器条（细竖条随 t 跳动）。

**心形线**
```
x(s) = 16 sin³ s
y(s) = -(13 cos s - 5 cos 2s - 2 cos 3s - cos 4s)
```
对 512 个采样点做 DFT，取前 N 个系数；绘图时圆链末端点随 θ 增加逐步铺满。

**动效**
- 拍 0–3：圆链从无序收拢到开始画线，N 从 0 涨到 18（计数）；
- 拍 3–5：心形闭合，金色线条变粗发光，淡粉填充从 0→0.25 透明度；
- 右侧数字实时更新，公式轻微呼吸发光。

**实现提示**
- 发光：预渲染一遍 `shadowBlur` 到离屏 canvas，再叠加；不要每帧对整幅画布开 blur。
- KaTeX 用本地 `katex.min.css/js`，`katex.render` 一次，后续只改 CSS 变量/透明度。

**音色**：FM 电钢琶音（每 1/8 音符，即半拍）+ 低频铺底；N 增长时加一层高频 shimmer。

## 03 极简发布会「更轻。更快。更聪明。」

**观感**：苹果式发布视频。黑场、巨字、金属光泽、极慢镜头，靠留白和反光显贵。

**调色板**
```
bg:     #050505 → #0b0b0d
metal:  #cfd4dc / #8f97a3
紫色轮廓光 #a58bff，橙色轮廓光 #ff8a5c
文字:   #f7f7f5
```

**构图**
1. 前 3 拍：居中新巨字「更轻。」「更快。」「更聪明。」80–120 px，第三个用紫→蓝→橙渐变（`createLinearGradient` 逐字裁剪）；
2. 第 4 拍起：Three.js 金属戒指居中偏下，占画面 45%；
3. 戒指下方：「Nova Ring」（Inter/Orbitron，字距从 0.4em 收到 0.12em）；再下一行「戴在指尖的 AI · 即将登场」小字；
4. 背景几乎纯黑，只有两盏轮廓光与地面极淡反射。

**Three.js 要点**
- `LatheGeometry(points, 256)`：圆角矩形截面（用 8–12 个点描述倒角），旋转轴 Y；
- `MeshPhysicalMaterial({ metalness:1, roughness:0.16, clearcoat:1, clearcoatRoughness:0.08, color:0xcfd4dc })`；
- `RoomEnvironment` + `PMREMGenerator` 提供反射；`ACESFilmicToneMapping`，曝光 1.0–1.2；
- 侧面 LED 细环：`TorusGeometry` 极细环，`MeshBasicMaterial` 颜色随时间 hue 循环；
- 紫色 `PointLight` 在左后，橙色 `PointLight` 在右前；地面用高粗糙度深灰平面接住反光；
- 相机从倾斜（y=0.5, lookAt 之后 lag）慢慢转正；扫光用一条沿 X 移动的矩形面光或环境贴图旋转近似。

**动效**：拍 0–2 文字逐字闪；拍 3 戒指淡入 + 轰鸣；拍 4 转正；拍 5 扫光到右侧，文字字距收拢完成。

**音色**：逐拍重低音（808 长音）；戒指出现时 sub boom + FM 钟声；扫光配 whoosh。

## 04 手绘白板「如何用 AI 做一支视频？」

**观感**：真实白板讲解的「沸腾线」手绘感；观众感觉有人正在边画边讲。

**调色板**
```
paper:  #f4efe6（+ 纸纹噪声）
ink:    #2a2724
red:    #c0392b（马克笔）
coral:  #d97757（强调）
```

**构图**
1. 标题（Long Cang）「如何用 AI 做一支视频？」，下方红色马克笔横线；
2. 中段：手绘灯泡（Long Cang「想法」）→ 右箭头 → 笔记本 `</>`（「代码」）→ 右箭头 → 场记板（「视频」）；
3. 最后红圈圈住「代码」，旁注「关键一步！」；
4. 一支马克笔图标跟随当前绘制点。

**技术**
- SVG path 用 `stroke-dasharray = pathLength`、`stroke-dashoffset` 从 pathLength→0 逐笔绘制；
- 手抖：`<filter><feTurbulence baseFrequency="0.02 0.04" seed="S"/><feDisplacementMap scale="2.5"/></filter>`，每 1/8 秒切换 seed（沸腾线）；
- 纸纹：一次生成的 CanvasPattern/噪声图层，不要每帧重算；
- 镜头：`camera = 1.65`，中心跟随笔尖位置（对 world 坐标做 `screen = (world - camCenter)*camera + center`），结束时拉远到 1.0 展示全图。

**动效**：拍 0–1 标题；拍 2 灯泡+箭头；拍 3 笔记本；拍 4 场记板；拍 5 红圈+旁注+拉远。

**音色**：尤克里里扫弦（每拍）+ 马克笔摩擦噪声（带通 2–4 kHz，与笔尖运动同步）。

## 09 代码录屏「t = 当前时间（秒），每帧都在变」

**观感**：真实开发者在写渲染代码，右侧预览实时生效；观众相信“这真是代码画的”。

**调色板**
```
editor bg: #15171c
sidebar:   #1b1e24
text:      #d7dae0
keyword:   #c792ea / function #82aaff / number #f78c6c / string #c3e88d / comment #546e7a
highlight: rgba(255,255,255,.06) 当前行
```

**构图**
1. 编辑器窗口（红黄绿按钮 + 文件名 tab `renderFrame.js`）；
2. 左侧文件树（renderFrame.js / palette.js / index.html / fonts / audio / README.md / package.json）；
3. 中间代码区：行号 + 9 行代码逐字打出，当前行高亮；
4. 右侧预览区：圆沿 8 字轨迹运动、HSL 随时间变色，随代码进度逐步生效，最后一条 lighter 光带拖尾；
5. 底部时间轴/状态栏；
6. 气泡：「t = 当前时间（秒），每帧都在变」；
7. 镜头 1.55× 跟随光标，最后滑到预览区。

**代码内容（9 行示意）**
```js
function renderFrame(t) {
  const r = 340 + 60 * Math.sin(t * 2);
  const x = 960 + r * Math.cos(t * 3);
  const y = 540 + r * Math.sin(t * 6);
  ctx.fillStyle = `hsl(${(t * 60) % 360} 80% 60%)`;
  ctx.beginPath();
  ctx.arc(x, y, 26, 0, Math.PI * 2);
  ctx.fill();
}
```

**实现提示**：逐字文本用「字符索引 = floor((t - start)/charPerSec)」；预览代码按相同规则“已生效行数”，保证音画与代码同步；拖尾用环形缓冲，不要无限叠加。

**音色**：lo-fi 电钢 + 黑胶噪声 + 键盘敲击声（与逐字同步）；和弦轻柔，不要抢卡点。

- 中心白色圆台（CylinderGeometry 或 Lathe 圆角）；
- 珊瑚色环面结（TorusKnotGeometry 或环形叠放），缓慢自转 + 上下浮；
- 玻璃球：`MeshPhysicalMaterial({ transmission:1, roughness:0.05, thickness:1.5, ior:1.5 })`；
- 金属金球：metalness 1 / roughness 0.15；马卡龙圆角方块（RoundedBox 或 extrude 圆角）；
- 硬币叠（多个扁 Cylinder）；3 个彩色小球按拍弹跳 + 挤压拉伸；
- `RoomEnvironment` + PMREM 提供反射；ACES 色调映射；
- 相机从远处推近并环绕（参数化 `camera.position`，不要 OrbitControls 自转依赖时间）。

**动效**：拍 0–1 卡片式大标题可省略（风格段以画面为主）；拍 2 环面结浮起；拍 4 三个小球同时弹跳；拍 5 相机推到最近。

**音色**：FM 钟声琶音 + 小球弹跳的「boing」（短滑音）。

## 附：风格时长与镜头语言的通用建议

- 3 s 内最多两次镜头运动（推近、环绕），不要又推又摇又切；
- 每个风格段结尾 0.3 s 做一个「收力」小动作（元素停稳/光晕衰减），让硬切更有力；
- 若风格段信息不足，用背景细节（粒子、纹理、光线）补密度，而不是加大标题字号；
- 色调统一策略：整片以黑底 + 珊瑚强调为骨架，风格段允许各自色板，但片头/卡/结尾回到品牌色。

## 主题 × 风格段：换色规则

上面那条「黑底 + 珊瑚强调」是无主题参数时的默认视觉（`coral-noir`）。启用主题系统后，**骨架色随主题整体替换**，风格段是骨架里的内容色块。主题的唯一数据源是 `templates/themes.js`，8 套主题的逐项说明见 `references/themes.md`（§8 选型矩阵、§9「覆盖主色 `accentOverride()`」）。

**三条规则**

1. **骨架跟主题走**：页面用 `?theme=<id>` 选主题，背景调 `drawThemeBackground(ctx, theme, W, H, t)`，胶囊/倒计时/水印用 `chrome(theme)` 的 `capsule` / `countdown` / `stamp` / `flash`。这一层不允许逐段写死颜色。
2. **风格段色板默认保留**：本文件第 01–11 节的调色板是风格辨识度的一部分，默认原样使用；只把左上胶囊编号色、右下倒计时、右上品牌水印换成主题 chrome。
3. **排他性主题才换色**：`claude-light` / `aqua-morandi` / `celadon-paper` / `blueprint-stone` 是整片浅底主题，与多数深底风格段冲突，用两种手段调和：
   - **主色替换**：用 `theme.accents` 轮换替换风格段主色/高亮色（色相统一、明度不变）；
   - **主题染色**：在该段画面上叠一层 4%–8% 的主题底色（全屏矩形或径向渐变），成本低于重画色板。
   暗色主题（`coral-noir` / `amber-noir` / `graphite-signal` / `crimson-theater`）与深底风格段天然兼容，默认不换色，最多把最跳的强调色换成主题 accents。

**每套主题推荐适配的 3 个风格段**（每段只换 1–2 个颜色，第三处留给白/黑）
