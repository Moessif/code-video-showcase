# 大字卡与字体系统

大字卡是整片的「标点」：1 s / 2 拍，把“你想做什么类型”砸给观众，然后硬切到风格段。样片 12 张卡（11 张 + 「还有更多?」），证据在 `../assets/card-tiles.jpg`。

---

## 1. 四套版式

| 版式 | 底 | 第一行 | 关键词 | 下划线 | 文字进入 |
|---|---|---|---|---|---|
| A 强调色底 | 卡片强调色（如 #ffcf5c / #ff2bd6 / #c792ea） | 黑 70 px | 黑 170 px | 黑色 8–12 px | 左右滑入 + 遮罩上推 |
| B 米白底 | #f4efe6（纸纹 + 1px 网格） | 黑 70 px | 黑 170 px | 强调色 8–12 px | 遮罩上推 |
| C 黑底（居中） | #0e0e0d | 白 70 px | 强调色 170 px | 无 | 砸入 |
| D 黑底（左对齐） | #0e0e0d | 白 70 px | 强调色 170 px | 无 | 砸入 |

样片实际循环：**A → B → C → D**，按轮次取 `layout = (round - 1) % 4`。也可以按任务书的 `i%4`（黑/强调/米白/黑），两者都成立，选一种坚持用。

**安全区**：左右 96 px、上下 80 px；关键词最长 8 个汉字时字号不超过 200 px；`STYLE 0X / 11` 固定在右下 (96, 1040) 附近。

---

## 2. 两拍时间线

```
t=0.00  第 1 拍：第一行(小字)砸入 + 速度线 + 径向光晕 + 抖动 6px
t=0.50  第 2 拍：关键词+后缀(大字)砸入 + 更强的速度线 + 抖动 12px
t=0.61  砸入结束，画面稳定
t=1.00  硬切到风格段（风格段第 1 帧即卡点冲击）
```

**砸入参数**（两行相同）：
- scale `1.7 → 1.0`，时长 0.11 s，`outExpo`；
- blur `16 px → 0`，时长 0.11 s（**不要每帧 ctx.filter**，见第 5 节）；
- 透明度 `0 → 1` 用 0.06 s；
- 文字基线：第一行在画面中心上方 118 px（即旧行上移量），关键词在中心偏下。

**速度线**：从文字中心向两侧/四周发射 20–40 条细线，长度 120–600 px，颜色 = 强调色，透明度随距离衰减，0.16 s 内拉长后消失。

**径向光晕**：文字中心一圈强调色 radial gradient，半径 500–900 px，峰值透明度 0.18–0.28，0.2 s 内衰减。

**画面抖动**：文字层整体 `translate(±shake, ±shake)`；第一拍 6 px、第二拍 12 px，用衰减正弦或白噪声×指数衰减，0.16 s 内归零。

---

## 3. 背景元素

- **描边回声大字**：字号 600 px，`strokeStyle = 白色 @ 6–10%`，`lineWidth 2–4`，内容 = 关键词，水平漂移 ±60 px（t 的正弦），放在文字后方；
- **细线网格/流线**：卡片版式 C/D 常见斜向极细速度线，透明度 5–8%；
- **纸纹/噪声**：版式 B 的米白纸纹，预渲染一层，透明度 6–10%；
- **角落信息**：右下 `STYLE 0X / 11`；样片还有极淡的页面边线/角标。

## 4. 字体与排版

| 用途 | 字体 | 建议 |
|---|---|---|
| 中文主力 | Noto Sans SC（100–900 可变） | 大字卡关键词用 900（Black），第一行 700 |
| 英文/数字 | Inter（可变） | 大字卡后缀、统计数字 |
| 等宽/代码/开场 | JetBrains Mono | 开场打字 76 px；代码段 |
| 衬线结尾 | Noto Serif SC（400/500/600/700） | 结尾两行；30–40 px |
| 书法 | Ma Shan Zheng | 水墨段竖排、印章旁 |
| 手写 | Long Cang | 白板段全部手写文字 |
| 活泼 | ZCOOL KuaiLe | 科普标题 |
| 赛博 | ZCOOL QingKe HuangYou | 赛博副标题 |
| 像素 | Press Start 2P | 8-bit HUD |
| 科幻 | Orbitron | 赛博主标题、发布会英文 |
| 海报/斜体 | Playfair Display（italic） | 结尾品牌名 190 px |

- 关键词 280 px 理论值在 1080p 上偏大；样片用 ~170 px 更接近海报比例。**做新片时以“最多 8 个汉字放得下”为准**，不要死守 280；
- 开场：76 px 等宽、行高 118 px；旧行上移 118 px 并降到 35% 亮度；
- 卡片第一行与关键词的间距 ≈ 0.25×关键词字号；
- 中英混排时给英文加 0.02em 字距，避免拥挤。

## 5. 文字渲染的工程细节（重要）

1. **预渲染模糊层**：把文字在离屏 canvas 上分别渲染成 blur=0、blur=6、blur=16 三档（用 `ctx.filter` 一次），主循环里只做 `globalAlpha` 交叉淡化。模板 `big-card.html` 用 0/16 两档（已够用），三档更细腻。软件渲染下逐帧 filter 会慢 10× 以上。
2. **字体加载**：渲染前 `await document.fonts.load('900 170px "Noto Sans SC"', text)` 逐个字体 + 文本加载，再 `await document.fonts.ready`；否则第一帧会掉字/回退字体。
3. **文字测量**：根据实际 `measureText` 宽度做自适应缩放（尤其是 8 字以上的关键词）。
4. **描边/发光**：`shadowBlur` 只用于小范围文字，或预渲染后叠加；大范围发光用 radial gradient 更便宜。
5. **确定性**：速度线/抖动/回声字漂移全部用 `mulberry32(seed)` 和 `t` 计算，不要 `Math.random`。

## 6. 文案结构

```
第一行（小）：动词短语，3–4 字，如「想做」「想开」「想拍」「想录」「想要」
关键词+后缀（大）：名词短语 + 问号，如「科普视频？」「知识讲解？」「产品发布会？」
```

- 第一行是“钩子”，关键词是“品类”；后缀问号制造转场理由；
- 强调色 = 风格段的主色/情绪色，让卡片与紧接着的画面有色彩呼应；
- 最后一张特殊卡：「还有 / 更多？」，然后进入八连闪展示剩余风格。

**JSON 配置建议**：
```json
[
 {"first":"想做","keyword":"科普视频？","color":"#ffcf5c","layout":0},
 {"first":"想做","keyword":"知识讲解？","color":"#58c4dd","layout":1},
 {"first":"想开","keyword":"产品发布会？","color":"#a58bff","layout":2},
 {"first":"想做","keyword":"培训课件？","color":"#e0674b","layout":3}
]
```
渲染时遍历，所有时间常数从同一个 `CLIP` 表读取，保证画面/音频/字幕一致。

**模板查询参数**：`templates/big-card.html` 直接读 URL 参数 —— `?layout=0..3&index=1&total=11&color=%23ffcf5c&first=想做&keyword=科普视频？&brand={{BRAND}}`；批量渲染时把每张卡的参数拼进 `--page` URL（如 `--page "/big-card.html?layout=1&index=2"`）即可。

## 7. 胶囊标签与 HUD

**风格段左上胶囊**（每段必须有）：
- 圆角 999 px，内边距 18×14 px，底 `rgba(12,12,12,.72)` + 1px 边框 `rgba(255,255,255,.18)`；
- 内容：`<珊瑚色粗体编号> 风格名 · 分类`；
- 例：`01 扁平插画 · 科普`、`05 赛博故障 · 预告片`；
- 位置 (96, 72)，字号 26–30 px。

**其他 HUD**
- 右下 3 秒倒计时 `00:03 → 00:01`，字号 28–36 px，等宽字体；
- 右上品牌水印 `{{BRAND}}`，字号 20–24 px，透明度 0.35–0.5；
- 赛博/代码段允许更多 HUD（FRAME / SYS / SIGNAL / TC），但整体透明度不超过 0.6，不能抢主视觉。

**禁止**：底部字幕条、黄色大标题、低分辨率贴纸、与风格无关的装饰 emoji。
