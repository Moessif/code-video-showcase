# 参考样片实测拆解（DeepSeek V4.1-Flash 61s）

> 样本：`deepseek_v41_flash_61s.mp4`（26.9 MB；样片文件不随仓库分发，证据图与测量数据见下）
> 属性（ffprobe）：61.013 s 容器 / 61.000 s 视频 = 1830 帧；1920×1080；30 fps；H.264 3 323 745 bps；AAC 48 kHz stereo 196 833 bps。
> 证据图在 `../assets/`：`contact-1fps.jpg`、`opening-tiles.jpg`、`style-tiles.jpg`、`card-tiles.jpg`、`flash-tiles.jpg`、`ending-tiles.jpg`、`audio-spectrogram.png`；切点在 `../assets/scene-cuts.txt`，音频测量在 `../assets/audio-analysis.json`。

这份拆解回答两个问题：**成片实际长什么样**、**和原任务书有哪些偏差**。做新片时结构可以照抄，品牌与文案替换即可。

**切点规律**（详见 `scene-cuts.txt`，共 60 个）：
- 每轮固定两个大切点：`8+4k`（大字卡进入）、`9+4k`（风格段进入，u=0 即卡点）；
- 风格段开头 0–0.1 s 内常有 3–4 个连续微切（`9.000 / 9.033 / 9.067 / 9.100`），对应「白闪 + 缩放 + 抖动」的卡点冲击；这是可复刻的节奏特征。

## 2. 开场（0–8 s）逐秒观察

- 黑底 `#0e0e0d`，文字 76 px 等宽，珊瑚色方块光标；打字节奏与音效「键盘咔哒」同步。
- 6 行文案（样片品牌为 DeepSeek V4.1-Flash）：
  1. Hello，我是 `DeepSeek V4.1-Flash`。（品牌珊瑚色）
  2. 我不是视频生成模型。
  3. 我不能凭空生成任何一帧画面。
  4. 但是——我会写代码。
  5. 而代码，可以变成任何风格的视频。（“任何风格”彩虹渐变）
  6. （第 5 行之后直接进入爆炸）
- 每出一行旧行上移约 118 px 并变暗；代码三列从 4.1 s 起淡入，先灰后高亮、越滚越快。
- 6.6–7.95 s：代码字符向外炸成彩色粒子，主句放大发光；7.55–8.0 s 闪白，硬切第一张卡。

**复刻要点**：打字必须由 `t` 严格驱动（按字索引 `floor((t-start)/perChar)`），不要用 setTimeout；旧行上移量/变暗曲线写死；粒子爆炸使用种子随机（同一 t 固定布局）。

## 4. 11 个风格段（每段 3 s）实测

统一装置：
- 左上角圆角胶囊：`0X 风格名 · 分类`（珊瑚编号 + 白/黑字）；
- 右下角 3 秒倒计时 `00:03 → 00:01`（样片新增，任务书未写）；
- 右上角/角部品牌小水印或 HUD（如 `DEEPSEEK V4.1-FLASH`、`SYS:`、`FRAME`、`SIGNAL`）；
- 段内 1–2 个小标签胶囊（如「夏至·北半球夏天」「N=18」「θ=3.54」）；
- 无底部字幕。

逐段观察（对应 `style-tiles.jpg` 从左到右、从上到下）：

1. **扁平科普**：深蓝径向星空；太阳约在画面左上 35%，橙色分层圆 + 12 根旋转三角光芒；虚线椭圆轨道；地球从轨道左侧经前方到右侧，蓝海绿陆、白极冠、背光面压暗；太阳到地球有半透明锥形光束；标题「为什么会有四季？」左上，珊瑚高光条垫在“四季”下；标签胶囊弹出。
2. **数学动画**：深底青网格；金色发光线由 36 个本轮/DFT 逐段画出心形，画完淡粉填充；右侧标题「傅里叶级数：用圆作画」，公式 `f(t)=Σc_n e^{int}` 与 `c_n` 积分式（KaTeX）；实时 N=18、θ=3.54；底部频谱条。
3. **极简发布会**：黑底；前 3 拍巨字「更轻。」「更快。」「更聪明。」（第三个紫蓝橙渐变）；第 4 拍金属戒指（LatheGeometry 圆角矩形截面，PhysicalMaterial metalness 1 / roughness 0.16 / clearcoat，RoomEnvironment 反射，ACES）；侧面 LED 变色细环；「Nova Ring」与「戴在指尖的 AI · 即将登场」。
4. **手绘白板**：米白纸纹；Long Cang 标题「如何用 AI 做一支视频？」红色下划线；手绘灯泡「想法」→ 箭头 → 笔记本 `</>`「代码」→ 箭头 → 场记板「视频」；红色马克笔线；最后红圈圈出「代码」+「关键一步！」；marker 跟随笔尖，镜头 1.65× 跟随、结尾拉远。
5. **赛博故障**：紫黑天空、条纹落日、城市剪影窗灯、洋红透视线地面滚动；Orbitron 大标题做青/洋红 RGB 分离；副标题「未来 · 已编译」；每拍一次故障（横切片错位、差值色块、整帧通道偏移）；扫描线/噪点/HUD 帧计数（SYS/FRAME/RGB SPLIT/SIGNAL/TC）。
6. **水墨国风**：宣纸纤维 + 暗角；三层 fbm 山峦，墨色上淡下浓，带皴擦；朱红落日；渔舟垂钓、飞鸟、云雾带；右侧 Ma Shan Zheng 竖排「山水之间」逐字晕开；配「行到水穷处 坐看云起时」；结尾朱红印章「代码」。
7. **数据可视化**：深色电影感 + 紫红光雾 + 粒子；标题「播放量竞速」；条形图赛跑 2019→2026，条形发光、高亮条珊瑚红；右侧大号描边年份（2022/2026）；CSS 3D 透视倾斜并缓转；右下玻璃卡「知识类内容 7 年增长 6.2×」；脚注“示例数据 · 仅作演示”。
8. **8-bit 像素**：240×135 低分辨率画布 8× pixelated；紫夜视差天空/山丘/地面滚动；原创橙色机器人两帧跑步；按拍跳跃、吃金币 +300、跳过绿色史莱姆；顶部 Press Start 2P HUD：SCORE 001800 / TIME 54 / 生命×06；结尾闪烁 STAGE CLEAR。
9. **代码录屏**：深色编辑器窗口（红黄绿按钮、文件树、行号、当前行高亮）；逐字打出 9 行 `renderFrame` 代码；右侧预览随代码进度生效，最终 lighter 彩色光带拖尾；气泡「t = 当前时间（秒），每帧都在变」；镜头 1.55× 跟随光标、最后滑到预览。
10. **Three.js 三维**：桃色无缝影棚 + 柔光；白色圆台；珊瑚色环面结漂浮旋转；玻璃球（transmission）、金球、马卡龙圆角方块、硬币叠、3 个按拍弹跳挤压的彩球；环境反射 + 软阴影；镜头环绕推近。
11. **竖屏短视频**：中央 9:16 手机（紫粉渐变屏幕）；逐拍弹出描边大字「用代码 / 做视频 / 有多快？」；三张步骤卡「写代码 / 逐帧渲染 / 一键成片 ✓」；点赞数上涨、双击大爱心、飘心；左侧描边「9:16」；右侧评论气泡「这也是代码做的？？」「求教程！」「学到了，已关注」。

## 5. 八连闪（53–55 s）

每 0.25 s 一切，切点带 1.08→1 缩放 + 白闪。样片画面：

1. 波普漫画：黄色半调网点 + 红黑爆炸星形「广告！」+ `NEW!` 贴纸 + 漫画线；
2. 孟菲斯：奶油底 + 黑色大「Vlog」+ 青/粉几何碎片 + `365 DAYS` 标签；
3. 瑞士海报：米白底 + 巨型灰「MV」+ 红/黑方块圆 + `MUSIC VIDEO` 小字；
4. 霓虹砖墙：`音乐现场`（青）+ `LIVE`（粉）霓虹框 + 砖纹 + 辉光；
5. 胶片纪录片：上下片孔、暖色场景、衬线「纪录片」+ `A DOCUMENTARY`；
6. 蓝图：蓝底白线稿手机 + `产品演示 PRODUCT DEMO` + 网格/标注；
7. 环形频谱：深色圆角卡 + 彩虹圆环频谱 + 「播客 PODCAST」+ 波形；
8. 弥散渐变玻璃卡：「2026 年度总结 ANNUAL REVIEW」毛玻璃卡 + 光斑背景。

**规律**：每个画面只保留 1 个主视觉 + 1 个英文/中文副标题 + 1 个角标，0.25 s 内必须读懂；配色各不相同（黄/奶油/米白/霓虹/棕/蓝/暗彩/弥散）。

## 7. 音频实测

由 `assets/audio-analysis.json` 得出（通用分析工具 `scripts/analyze-reference.sh` 可对任意样片生成同类指标）：

- **速度 120.0 BPM**（能量包络自相关峰值），相位 0.0 s → 所有拍点落在整数/半秒上；
- 102 个强 onset 中 **86.3% 落在 120 BPM 网格 ±30 ms** 内，中位误差 **0 ms** → 卡点几乎样本级对齐；
- 大字卡起拍（8/12/16/… s）能量是前 300 ms 的 **8–9 倍**；风格段起拍（9/13/… s）是 **2.8–3.5 倍** —— 卡点比普通切点更重，符合“大字卡 drop-out + 2 拍打击”的设计（8–9 倍为典型值，逐拍在 4–12 倍间波动；风格段逐拍 2.8–3.7 倍，明细见 `assets/audio-analysis.json` 的 `expected_hits`）；
- 近静音区间：`0.00–0.56 s`（开场前）、`60.38–61.00 s`（结尾淡出）；
- 频谱图：0–8 s 稀疏（铺底 + 打字咔哒），8 s 后进入全频段律动；每 4 s 的结构在频谱上可见垂直分段。

## 8. 与原任务书的偏差（做新片时可自由选择）

| 项 | 任务书 | 样片实际 |
|---|---|---|
| 品牌 | Opus 5.5 | DeepSeek V4.1-Flash（片头/片尾/水印/故障标题全部替换） |
| 大字卡版式顺序 | `i%4`：黑/强调底/米白/黑 | 强调底 → 米白 → 黑 → 黑（4 循环） |
| 大字卡字号 | 150 px / 280 px | 约 70 px / 170 px，更偏海报感 |
| 风格段 HUD | 只要求左上胶囊 | 额外右下 3 秒倒计时、右上品牌水印/HUD |
| 发布会戒指 | 珊瑚色 | 铬银色，靠紫/橙轮廓光找回品牌感 |
| 数据段标题 | 数据可视化 | 「播放量竞速」，条目标签与数值不同 |
| 结尾统计 | 19 种风格 · 1830 帧 · 0 个视频生成模型 | 保留（“19 种风格”是风格总数，不是 11 轮） |
| 音频 | 未给实测 | 120.0 BPM、相位 0、86.3% onset 在 ±30 ms |

> 结论：**结构、技术管线、视觉语法可以严格照搬；文案、品牌、个别场景细节按新主题替换**。任务书本身已是一份高质量可复现说明，样片证明了这套管线可行。
